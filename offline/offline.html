Unofficial shell · 非官方壳

Network required (first time)

This app is only a desktop shell. It loads the official web configurator at https://ez.iqunix.com/. A first online visit is needed so Chromium can cache pages under Electron userData. No site assets are bundled in this portable app.

Connect to the internet, then click Retry. After that, later offline use may work from the local HTTP cache when the site’s cache headers allow it.

首次需要联网

本程序仅为桌面外壳，会加载官方网页配置器 https://ez.iqunix.com/。 便携版不包含该网站的任何资源；请至少成功在线打开一次，以便缓存在本机 Electron userData 目录。

请连接网络后点击「重试」。之后在站点允许缓存的情况下，离线时可能仍可使用已缓存内容。
